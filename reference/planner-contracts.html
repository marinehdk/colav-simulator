Reference 03

Planner 契约

区分规划器看见什么、执行什么、展示什么。

输入

  • ownship_state：6 维自船状态。
  • tracks：目标状态、协方差、尺度、观测时间与退化标志。
  • waypoints_enu_m / speed_plan_mps：名义任务。
  • enc / disturbance：环境约束与扰动。
  • 坐标和单位固定为 ENU / SI / rad。

输出

  • control_reference：9x1，本次求解后立即交给 Ship 的执行参考。
  • predicted_trajectory：9xN，规划器预测未来；主要用于验证、保持采样和显示。
  • control_trajectory：可选 9xN；存在时，非求解步优先从它采样。
  • status / feasible：求解结果是否允许执行。
  • constraints / target_predictions：解释预测为何安全或不安全的证据。

9x1 与 9xN

9 表示每一列有 9 个参考量：

[x_d, y_d, psi_d, u_d, v_d, r_d, ax_d, ay_d, rdot_d]^T

9x1 是一个时刻的一列参考。9xN 是 N 个未来采样时刻并排；行表示变量，列表示时间。N 不是船舶数量。

             k=0        k=1             k=N-1
x_d        [ x0         x1      ...      xN ]
y_d        [ y0         y1      ...      yN ]
psi_d      [ p0         p1      ...      pN ]
...        [ ...        ...     ...      ...]
rdot_d     [ r0         r1      ...      rN ]

horizon_dt_s 表示相邻列的时间间隔。普通 Ship.forward() 每步只把一列 9x1 reference 交给 controller。

不可互换：预测轨迹不是已执行轨迹；reference 不是控制输入；控制输入也不是下一真实状态。
