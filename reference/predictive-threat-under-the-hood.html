predictive-threat 底层逻辑

一份用于读代码、查 trace、解释 UI 数值的压缩卡片。

一句话：每个仿真周期先冻结物理事实，再由纯评估器计算每船 threat vector；Lifecycle 负责有状态的 Primary/承诺，Coordinator 把它们合成一个不可变 snapshot。

  ├─ _encounter_cycle()                         # ownship + tracks

3. DCPA/TCPA 与船舶域

令 r = p_target - p_own，v = v_target - v_own：

range       = ||r||
closing    = -(r · v) / ||r||
tcpa_signed = -(r · v) / ||v||²
tcpa_forward = max(0, tcpa_signed)
dcpa        = ||r + tcpa_forward · v||
hull_clearance = dcpa - ownship_radius - target_radius

若相对速度接近零，TCPA/DCPA 不能假装精确；代码保留 DCPA≈当前距离，并记录 RELATIVE_MOTION_UNDEFINED。

Off-centred ellipse 的尺度：

a = (fore + aft) / 2 + uncertainty_radius
b = (port + starboard) / 2 + uncertainty_radius
c = (fore - aft) / 2
scale = sqrt(((forward - c) / a)² + (starboard / b)²)
scale < 1  → INSIDE     scale = 1 → TANGENT     scale > 1 → OUTSIDE

uncertainty_radius = multiplier × sqrt(max_eigenvalue(position_covariance))。V1 默认 multiplier 为 2。预测域在 horizon 每个 sample 计算 scale，取最小值；穿越 scale=1 的相邻点做线性插值生成 TDV/TDE。

5. Primary 不是 weighted risk score

ThreatAssessment 只产出 ranking facts；它不保存 Primary。唯一有状态的 Primary authority 是 EncounterLifecycle。

  1. hard hull/response-time emergency
  2. Rule 17 MUST_ACT
  3. 已承诺且 active
  4. current domain violation
  5. predicted domain violation
  6. future severity/completeness
  7. approaching TCPA、DCPA、range、TrackKey/generation tie-break

普通 challenger 需经过 physical-time hysteresis；emergency 或 MUST_ACT 可立即 preempt。Lifecycle 的 required targets/directive 不能因为 UI 或另一个 target 排名更高而被删除。

6. Schedule 与 Conflict Graph

每个 TrackKey 在一个 snapshot 只能占一个 schedule context：

CURRENT_PRIMARY → Lifecycle primary
CONCURRENT_REQUIRED → Lifecycle aggregate directive required set
NEXT → current/predicted domain violation，但尚未成为 obligation
MONITOR → 保留 observation/evidence，无当前 obligation
RELEASED → 已释放，但 evidence 保留

Direct edge：两个完整 Threat Window 的时间区间相交。Plan-induced edge：只在 baseline、fresh accepted receipt、target/profile/prediction identity 和 hash 全部匹配，且 accepted plan 造成新 violation、至少提前 5 秒 TDV 或 scale 恶化至少 0.1 时生成。Edges 做 input-order-independent connected components；A-B 与 B-C 会形成一个 cluster。

7. 最后一道边界

  • Threat Domain 是 anticipatory/advisory evidence，不是 L4 hard safety gate。
  • Mid-MPC assembler 消费 Lifecycle directive 与 tracked targets；浏览器不重新算 CPA、domain、Primary、window 或 cluster。
  • API/WS 只投影 backend ThreatManagementSnapshot。缺 snapshot 时前端显示 UNAVAILABLE，不推断“安全”。
