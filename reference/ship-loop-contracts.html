Reference 02

Ship 闭环契约

一艘船如何把目标信息变成下一物理状态。

主链

true_do_states -> tracker -> tracks -> COLAV/guidance -> references -> controller -> input -> model -> state

数据形状

  • state：6 维，通常为 [north, east, psi, u, v, r]。
  • track：目标 ID、4 维 ENU 运动状态、4x4 协方差、船长、船宽。
  • references：9xN；当前控制器只消费第一列。
  • input：通常 3 维广义力和力矩 [X, Y, N]。

三种 planning 模式

  1. _colav != None：避碰算法生成 references。
  2. _guidance != None：LOS 等制导生成 references。
  3. 两者均为空：外部 actor 通过 set_references() 控制，供 RL 使用。
注意：算法输出不是船位。它先成为 references，再经 controller 与 model 才改变 state。
