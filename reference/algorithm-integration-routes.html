算法接入路径

先判断用途，再选择最小接入边界。

内置算法IntegrationRegistry.build_algorithm() 显式分支。适合仓库长期维护的核心算法。
动态插件algorithm_config.factory = "module:callable"。当前 factory 必须返回 core COLAV 的 CustomMPCAdapter。
固定外部集成integrations/*.py 包装外部仓库，如 PSB-MPC、RRT、RLMPC。
RL 训练COLAVEnvironment + remote_actor=True。agent 外部写 references，不走普通 Ship0 内部 planning。

动态插件最小契约

  1. factory 接收 FactoryContext。
  2. 返回 colav_simulator.core.colav.custom_mpc_adapter.CustomMPCAdapter。
  3. AlgorithmDescriptor.algorithm_id 与请求 ID 完全一致。
  4. solve 接收 PlannerInput，返回 MPCSolution。
  5. 依赖、配置和源码身份进入 build identity；失败不可静默 fallback。
同名警告：core/colav/custom_mpc_adapter.py 与 guidance/custom_mpc_adapter.py 是两个不同边界。实验插件工厂要求前者。
