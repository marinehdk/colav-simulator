## Data contract

`gnc_balance` is an additive telemetry field generated by
`gui_server/gnc_balance.py::balance_telemetry` from the executing ownship stack.
It does not advance physics or sample random/environment state. Legacy returns
null. Existing stack identity evidence remains in `modular_gnc`.

| Card | Source | Units and missing-data behavior |
|---|---|---|
| ROLL | `stack.modules.plant_state()` | Roll in degrees, roll rate in degrees/second; starboard-down positive. Peak absolute roll is the largest received value since this browser connection/session, not an operating limit or full-run maximum. Unsupported roll is unavailable. |
| Environment | Held `environment_truth()` | True wind speed in knots and FROM bearing relative to true north; current in knots and TO bearing; wave Hs in metres, Tp in seconds and TO bearing. No fabricated apparent-wind or forecast values. OFF is explicit, channels show dashes. |
| Propulsion | `actuator_trace()`, `allocator_solution()` and selected layout | Three main thrusts, two physical rudder angles, two bow thrusts. Actual and command are distinct; kN/degree readouts. Native thrust instruments show signed fraction of the selected ahead/astern capacity. Rate limiting, health and bow lockout are visible. Ideal stacks have no physical-actuator readings. |
| Constraints | Normalized controller/actuator parameters and selected layout asset | Heading-reference ROT is explicitly labeled as a reference-shaper limit, not maximum physical vessel ROT. Rudder angle/rate, thrust rates, bow thresholds, PID bounds and actuator capacities come from the selected config. Weather operating limits are not configured. |

Forecast is explicitly unavailable, as confirmed by the user. Mini trends contain
only received actual samples (up to 120), with simulation time span in their
accessible title. Session/config changes clear histories and old actuator values.
Map interpolation reuses a physics tick; the monitor skips repeated tick renders.

## OpenBridge and design references

Pinned `@oicl/openbridge-webcomponents@1.0.1`, bundled locally. Added native
`obc-roll`, `obc-rudder`, `obc-thruster` and `obc-graph-mini`; readouts reuse
`obc-automation-button-readout-stack`. Its numeric value mode rounds to integer,
so formatted text readouts preserve decimals without modifying the component.
No RPM, power, pitch, heeling estimate, weather safety threshold or sail data is
invented to fill reference artwork.
