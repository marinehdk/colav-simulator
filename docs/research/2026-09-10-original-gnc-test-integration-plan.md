## 2. 需要回答的三个问题

| 问题 | 证据 | 不足以作为证据的做法 |
|---|---|---|
| 原版本来怎样运行？ | 原源码及有效配置在 A4000 原生运行，记录实际输入、输出、时序和模式 | 只看源码或旧报告；只运行提取后的 C++ |
| 提取后是否保留原行为？ | 相同初态、输入事件、dt、配置和随机实现下，逐步与原源码独立回放比对 | 只比较末端位置；两个程序调用同一个提取库；互相回放自己的输出 |
| 本框架和已有避碰算法能否驱动它？ | 从产品入口创建新后端，真实 VO/Fan/Mid 计划经原仲裁、导引和执行链形成闭环 | 直接给原 PID 填航向绕过导引；把预测轨迹当实船位置；使用现有 Full 代跑 |

三项分别给结论。原版和嵌入版同样未精停，可能证明迁入保真，同时表明任务性能未通过；不能为了让原版通过而先调参。

## 3. 三条执行链与对照顺序

### R0：A4000 原生 ROS2 运行

原冻结源码、原正常 launch 语义、原有效配置。仅做隔离部署、输入注入及观测采集。

外部节点订阅能得到的状态直接采集。对关键内部状态、实际消费输入和 dt，允许添加最小只读 trace hook；补丁必须独立保存并逐项审阅。它不得改变控制分支、更新顺序或反馈，不把未采集状态写成零。

原源码、构建兼容补丁、只读采集补丁分别哈希。trace 开启/关闭短程对照并报告开销，避免采集开销本身改变实时行为。缺失 README 等只在独立暂存副本修正安装清单，不改冻结源。

### R1：A4000 原源码固定事件回放

从 R0 记录提取每个模块实际消费的输入、调用时间、dt、初态和随机状态，在独立原源码参考构建中重放。

R1 允许测试驱动替代 timer/外部消息输入，但算法实现来自冻结原版，不得链接本地提取库，也不得复用生产提取器生成的算法文件。回放驱动和插桩差异单列。先证明 R1 能重现 R0 的相同调用输出，再用它判断本地提取的数值差异。

无法采集完整隐藏状态时，采取从冷启动按完整事件序列重放；不得凭猜测构造中途快照。无法回放的项标为未验证，不纳入匹配百分比。

### E：本地提取版与产品嵌入

E0 为直接调用原 C++ 核心的本地回放；E1 为通过本框架 IShip Adapter 和真实产品入口执行。

顺序：R0→R1 一致性；R1↔E0 相同输入逐步匹配；E0↔E1 相同外部事件匹配；最后 E1 自主闭环运行与 R0 航线行为比较。

这样可以区分：原版自身问题、参考回放错误、C++ 提取误差、框架接线错误和规划可执行性问题。

第一阶段参考构建与嵌入构建尽量在 A4000 使用相同编译器比较以排除平台差异；随后在 Mac 上运行相同向量确认跨平台表现。A4000 上的提取版也必须能在不加载 ROS2 的进程中执行。

## 4. 冻结内容与原版语义

每次 campaign 冻结以下内容，并写入机器可读 manifest：

1. 原源码清单、提取补丁、测试驱动、项目 commit、工作区改动哈希。
2. 编译器、C++标准、优化选项、Eigen版本、系统架构、Python/绑定版本。禁止开启破坏浮点语义的 fast-math。
3. 原默认参数、generated YAML、launch 覆盖、运行参数导出的合并结果及每个值的来源。
4. 本船尺寸/质量/惯性/水动力、执行器位置与限值、控制/导引/分配参数、有效能力开关。
5. 初始位姿、全部速度、执行器状态、积分/滤波器/模式状态、随机种子及必要的随机引擎状态。
6. WGS84原点、投影、角度和速度语义、消息和字段单位。
7. 模块更新周期、首次调用时间、同一时刻事件次序、输入保持与失效规则。
8. 航线、速度上限数组、模式、初始偏差、环境、运行时限及比较器版本。

只按 YAML 推测运行周期不够。当前 generated YAML 可见导引0.5 s、控制0.1 s、动力学50 Hz；须与节点构造和 launch 最终值核对。原分配还可能由控制输入回调触发，不能看 update_rate 就额外循环一次。

原 arrival_radius=15 m、speed_at_arrival=0.3 m/s、导引 final_capture_radius=100 m 各有自身语义，不能直接组合成一个“原版到达标准”。必须记录原模式转换和条件，再另报统一位置/速度指标。

原 sensor_fusion 默认未在正常 launch 中启动、NDO被显式关闭，保持该基线。单独验证可选能力时使用单独 case 配置，不把“有源码”当“默认已启用”。

## 5. 分层测试

### L0：来源、构建和隔离

- 原183文件内容匹配；有效配置与资产完整，缺失即失败。
- 构建修改只涉及依赖、接口、观测或调度时，逐项记录；算法变动不混入原版后端。
- 本地无 rclcpp/rclpy/DDS 运行依赖；缺少本地库时显式不可运行，不能调用旧 Full。
- 多实例/重复 reset 不共享积分、随机状态或段切换历史。原导引存在函数局部 static 段切换时间，提取时必须显式处理实例归属，并用两个并行实例验证。
- 现有 Full OFF/ON ID、配置哈希及确定性回放不变。不能只以哈希不变代替行为检查。

### L4：航线接收与避碰计划合同

固定名义航线后，覆盖：首个避碰计划、同ID重复、更高版本、过期、父路线版本不符、乱序、无回线点、恢复名义线、明确取消、规划暂停/超时，以及原能力门限两侧。

重点覆盖当前原版10秒航线更新保护与现有Mid 5秒规划周期的组合；先实测哪些更新被接受/拒绝。不得假定每次MPC求解都应强制刷新原航线。

请求、原仲裁应用计划、原导引平滑路径、最终执行状态四份数据分别保留。原生的计划降速、拒绝与PGD Level-2/3分开统计。

任何必须改变路径几何、有效期或原保护阈值的兼容方案先成为独立提案；原版后端保持冻结，不在L4测试中偷偷修复。

### L5：本框架已有避碰算法闭环

沿用现有 VO、`potocnik_colreg_fan_mpc`、`mid_mpc_ipopt` 的固定配置与真实求解器。每种跑HO、CS、OT、多船四类，E0及一个固定原版组合环境各一遍，共24格。

首先将各算法已接受计划作为固定输入分别驱动R0与E，以隔离GNC。然后再跑两边自主闭环；此时状态微差可能使优化器选不同解，不能把轨迹不完全重合直接归咎于GNC迁移。

闭环每格报告：

- 实际算法/控制/分配/船体身份、规划次数、GNC接受/拒绝次数、墙钟期限表现。
- 本船对每个目标及静态障碍的连续步间最小安全距离；目标间碰撞另列，不隐去。
- 既有COLREG行为门与本船安全分别判定；无法完成的评估明确标缺项。
- 名义航线和活动避碰线XTE分别计算，任务回归、航行进度和末端状态分别记录。
- 同时报告原GNC末端状态、框架原生goal判据和统一位置/速度指标。不同算法原生到达门不混用。
- 原GNC分级降级保留；严禁静默切回旧Full、理想执行或其他避碰算法。

还需辨别计划给的是地速/航迹向还是对水速度/艏向。原后端身份不能复用现有Full的能力资格；原响应测试所得能力数据单独登记。若已有算法超出原GNC能力，应作为兼容性结果报告，先不改算法或原GNC。

## 6. 匹配程度：指标与拟定门槛

不使用一个“99%匹配”总分。报告至少给出六类覆盖率和原始误差：来源、配置、数值、状态机、调度、闭环结果。

### 同输入逐步匹配（R1↔E0，E0↔E1）

离散字段完全一致：模式、段索引、计划ID/版本、接受/拒绝及原因类别、保护标记、分配级别、到达事件。同值字段与缺失字段不相等。事件允许的时间偏差为0个内部tick。

连续量采用 `abs(E−R) <= atol + rtol*abs(R)`；以下是v1拟定起始门槛，须在首批测试前冻结，不能看到失败后自动放宽：

| 字段 | atol | rtol |
|---|---:|---:|
| 本地位置 | 1e−6 m | 1e−10 |
| 速度 | 1e−8 m/s | 1e−9 |
| 艏向/横摇/舵角，使用环形角差 | 1e−8 rad | 0 |
| 角速度 | 1e−9 rad/s | 1e−9 |

全体受测步必须通过，不用“99.9%的步通过”掩盖切换边界差异。报告首个差异的模块、字段、期望/实际、容差、上一帧状态和输入事件。

同硬件/编译器和跨平台分别统计；编译器和数学库差异只有在定点回放定位后才可归类。若门槛确需修改，版本化比较器、解释依据，并同时保留旧门槛结果。

### 闭环匹配

确定性原源码驱动与嵌入版使用同调度、同初态自主闭环时，另设累计漂移观察门：最大位置差0.10 m、最大速度差0.01 m/s、最大艏向差0.05°，关键模式事件与路径段序列一致。它不替代逐步门，也不是45米船的实船性能指标。

R0原生ROS连续运行存在调度抖动：以采集的真实时间和重复运行包络作比较，不承诺其与嵌入版逐位一致。至少对直线偏差、左右转弯、S形、终点保持、组合环境做3次原生重复；若自身重复性差，报告原生基准的不确定性。

只允许统一已知坐标原点、单位和时钟零点后，在共同采样时间做明确记录的插值；不允许动态时间规整、寻找最佳时间延迟、平移旋转拟合、删除失败段来提高匹配。

每条航线展示：位置/速度/艏向/XTE差的最大值、RMSE、P95、末段偏差；舵角与推力总变差；饱和及Level-2/3时间占比；关键模式事件时刻；位置/速度同时满足观察条件的时段。RMSE分母、有效样本数和缺样数必须给出。

R0与E自主避碰闭环若输入计划已经不同，不计算一个伪装成迁移等价的逐点匹配率；回到相同计划回放后再定位原因。
