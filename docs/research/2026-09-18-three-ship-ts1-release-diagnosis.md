## T≈500 s：领先余量是实际阻塞条件

截图对应 T514.2 s；最近求解快照是 T514.1 s。TS1 朝西航行，截图中较大的上下分离主要是横向间隔。

| 项目 | T514.1 s 实值 / 当前门槛 |
|---|---:|
| 沿 TS1 航向的纵向领先 | 42.831 m / 78.05 m |
| 横向分离 | 461.558 m / 56 m |
| 两船中心距离 | 463.541 m |
| 当前相对运动 signed TCPA | -403.058 s |
| 生命周期 | ACTIVE / COMMITTED |
| 允许归线 | false |
| 仅对 TS1 的向北归航 CPA 门 | 已通过，signed TCPA -71.05 s |

领先门槛由 `_passing_geometry_clear()` 定义：

```
纵向领先 >= 本船长度 / 2 + TS1 长度 / 2 + hard_hull_clearance_m
         >= 44.1 / 2 + 12 / 2 + 50 = 78.05 m
横向分离 >= 8 / 2 + 4 / 2 + 50 = 56 m
```

本船中心已经在 TS1 前方，但未满足当前代码的纵向解除余量。界面 TCPA=0 是前向 TCPA 截断后的读数，不代表解除全部条件已经满足。反事实谓词检查仅增加纵向领先到门槛，保持横向位置不变，passing-clear 会由 false 变成 true。归航 CPA 门本身对 TS1 已经通过，因此本时刻不是该 CPA 门阻止归线；任务航段也已经是正北，并非仍选中了西向旧航段。

这只是单目标谓词诊断，**不是提前北转完整轨迹已经通过验证**。其他目标、海图、连续船壳间距及真实 GNC 跟踪仍需共同验证。
