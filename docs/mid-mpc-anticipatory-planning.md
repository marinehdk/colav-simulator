# Mid-MPC 提前规划与分阶段执行

2026-09-08，基于 `46903f76`。实现用户已确认的提前规划方案；搁浅预测仍为下一步 TODO。

## 行为

多目标 Mid-MPC 持续评估目标，并为已识别的未来接触安排暂定动作时间。远期目标保持 CANDIDATE / NEXT，不立即升级为当前已锁定的避让动作；进入动作阶段后才确认 ACTIVE。真实的当前碰撞或紧迫 CPA 可以立即抢占未来安排。

预测窗口内的计划可以包含多段 `MISSION → ALTER → PASS → RECOVER → ALTER…`。近期控制执行计划前段，未来避让写入后段参考和逐时段航向约束。所有被跟踪目标仍进入独立 L4 安全检查；计划涉及的物理安全行不会随预计恢复阶段关闭。

400s 优化窗口、80×5s 网格和原求解周期不变。窗口外只有带绝对时间的暂定安排，没有伪造超过窗口的优化轨迹。目标状态、接触类型、任务航段和安全证据变化时重新评估；计划时间不是无条件执行预约。

单目标和其他算法继续采用原路径；本次没有修改它们的动作调度。

## 实现边界

- **Lifecycle**：在同一权威状态中维护 `planned_action_at_s`，区分未来安排与当前义务。动作提前量由既有转速、速度、所需转角、预测间距缺口及动作响应时间推导，不使用场景编号、固定仿真时刻或目标编号分支。
- **动作提前量**：转向所需时间 + 间距缺口 / 预计横向速度 + 既有动作完成与确认窗口。间距缺口按既有 comfortable clearance、船体半径和不确定性计算；包含既有最小改善量。该表达式是工程计划估计，不是 COLREG 法定阈值。
- **Horizon compiler**：每目标独立的动作/恢复窗口及避让航向，组合为按阶段变化的参考。未来避让基准使用未来任务航段切线，避免把返航时的 LOS 收敛方向误当成后续航段方向。
- **NLP**：逐控制区间的 `course_bounds_rad` 写入既有决策上下界，不增加决策维度。时序性航向约束替代同一避让方向作用于整个窗口的旧表达。初始解修复同时遵守这些上下界。
- **L4 / evidence**：保留数值、全部目标物理安全、当前义务和执行能力检查。证据增加目标动作窗口，支持中间恢复后再避让；HOLD 时同步平移阶段窗口。未来 CANDIDATE 没有立即动作义务，其未来约束仍在原数值问题中验证。
- **数值停止**：当未来计划的种子已满足全部原始约束、当前没有动作航向界且目标函数接近零时，采用既有 nominal quality ceiling，避免求解器为了改善近乎最优的种子耗尽 deadline。仍需真实 IPOPT 迭代和独立 L4，不直接执行种子。
- **Threat / UI**：未来安排不竞争当前主威胁，NEXT 按暂定动作时间排序。紧急判断在新模式下读取 canonical physical facts，避免把几百秒后 CPA 的负船体间距误认为当前碰撞。卡片显示 `Planned maneuver ~T=…s · provisional`；`ONLY TARGET` 改为 `ONLY ELIGIBLE`。

所有时间使用仿真绝对秒，编译为 5s 控制区间；坐标维持现有 NE、角度为弧度。未放宽物理安全距离、未增加 slack、未替换求解器或引入 fallback。

  - 每帧检查船间距离。被拒候选只允许继续已获验收的计划，不要求优化器永远不拒绝候选。

## 限制与后续

本轮验证的是指定仿真配置下的提前规划和执行，不是所有多船布局或 MASS-L3 系统验收。当前配置没有搁浅事件，**不代表已有搁浅预测能力**；ENC 陆地、不可航浅水、吃水及安全余量进入候选轨迹可航性检查，仍是下一步 TODO。
