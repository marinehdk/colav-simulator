# Mid-MPC 有限终点与停车

2026-09-08，基于 `3869c6aa`。修复 OT / CS 末段预测越过 WPT2，以及到达判据未要求减速的问题；HO 同样采用有限终点语义。

## 根因

原目标函数跟踪巡航速度与航线横向误差，没有有限终点的停车参考。预测窗口越过最后航点后，优化器仍倾向维持巡航；遇到岸线/岛屿硬约束便转向绕行。HO 较低速度下的预测看似朝向航点，不代表具备停车能力。

最小复现：终点在前方 300m、初速 4m/s，原预测末点为 1600m。另有仿真结束判据仅检查距目标小于 7 倍船长，不检查速度。

低速闭环还暴露了重新激活问题：已释放的 OT 目标在本船减速后，被重判为本船被追越，尽管预计接近时刻已超出 400s 规划窗口。该即时义务撤销了停车参考，导致低速末段重新优化失败。

## 修改

- 在最后航段且当前避让义务允许恢复时，生成有限终点、渐减速度参考及终端位置代价。中间航段仍沿原任务路线推进。
- 参考速度计入减速度与响应预算；至少预留三个决策周期及一个预测步长，存在船速时间常数时还计入其四倍响应时间。这是经当前闭环验证的保守工程参考，不改变船体动力学。
- 终点位置与速度参考作为固定维度参数进入原 IPOPT 问题；不裁剪输出预测、不放宽 ENC/船间安全或零 slack 约束。停车阶段不再复用会继续巡航的旧种子。
- `COLAV_STRICT` 增加上述工程目标；`MASS_PARITY` 不增加终点目标。
- Mid-MPC 通过适配器的可选到达回调要求实测 **距离 ≤5m、速度 ≤0.05m/s**。其他算法保留原默认到达语义；显式半径查询仍只查询距离。
- 已释放目标的重新激活使用实际规划窗口；当前紧迫情况仍可抢占。所有目标的独立安全检查保留，未按目标编号或场景编号绕过规则。
- OT / HO / CS 场景时限由 600s 延至 1200s，给实际到达与停车留出时间。测试必须真正到达并满足停车条件，不能用时限耗尽代替通过。
