## 根因与修改

修改范围仅为严格模式的多目标 NLP 数值求解：

1. 未启用的船尾通过谓词返回恒定零，却保留 `0 >= 0` 的下界。该无实际约束作用的行没有内点，会导致 barrier/restoration 反复迭代。取消这些未启用谓词的下界；已启用的船尾通过谓词仍保留原下界。
2. 多目标约束使用单调 barrier 更新时，捕获的慢输入需要 115–124 次迭代。改为自适应更新。
3. 展开多目标 CasADi NLP 的函数求值，减少反复求值和 Jacobian 的开销；数学表达式、状态和决策维度不变。
4. 多目标 limited-memory history 从 50 调为 6，经冻结输入及闭环对照验证，降低迭代代价。
5. 多目标提前停止使用逐行严格容差：一般约束 `1e-6`，CPA `1e-4`。不再给所有单侧行统一 `1e-3`，避免快速退出后又因速度变化越界被独立 L4 拒绝。

按实际 NLP 图容量区分数值策略，不按场景名称、时间或目标编号分支。单目标已校准策略和 MASS_PARITY 路径保留。没有放宽碰撞距离、启用 slack、删除目标、跳过 L4 或换用 fallback。
